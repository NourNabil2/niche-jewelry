١. بيانات الدخول الآمنة للوحة التحكم (Executive Access)

٢. معمارية النظام والبيئة التقنية (Technical Architecture)

تم بناء المنصة وفق أحدث المعايير البرمجية لضمان سرعة فائقة، تجربة مستخدم سلسلة، وتوافق تام بين واجهات العرض ثلاثية الأبعاد وقاعدة البيانات:

Backend Engine (المحرك الخلفي) PHP 8.2+ مع Laravel 11، متحكمات مخصصة لكل قسم، ونظام Middlewares لحماية الجلسات وضبط اللغات (AR / EN).
Database Layer (قاعدة البيانات) MySQL / MariaDB بـ 9 جداول مترابطة تضمن حفظ المنتجات، الدلايات، تصاميم العملاء، والطلبات بدقة الميكرون.
Frontend & 3D WebGL (الواجهة) نظام قوالب Blade مع محرك Three.js للاستوديو التفاعلي ثلاثي الأبعاد، ودعم كامل للغتين العربية (RTL) والإنجليزية (LTR).
Dual Currency Engine (العملات) دعم مدمج للدولار الأمريكي ($ USD) والدينار الكويتي (د.ك KWD) مع التحويل التلقائي وإمكانية التخصيص اليدوي لكل قطعة.

مخطط تدفق العمليات (Architecture Flow)

المرحلة المسار / المكون الوظيفة والمسؤولية
المتجر الحي للزوار /ar أو /en تصفح الهيرو، التشكيلات الراقية، ومعاينة أسعار الذهب والقطع.
استوديو الصياغة 3D /:locale/atelier تخصيص الإسورة بوجهيها (16 دلاية)، دوران أفقي سلس، ونقش ليزري مجاني.
فحص العروض الفوري POST /api/promo/validate واجهة برمجية API تفحص صحة الكوبونات وتطبق الخصم لحظياً.
لوحة التحكم المركزية /admin/* إدارة الكتالوج، الدلايات، الطلبات، الكوبونات، البانرات، والبيكسل.

تحتوي قاعدة البيانات على 9 جداول أساسية مهيكلة لضمان التكامل التام:

الجدول (Table) الوصف الحقول الأساسية الحالة

orders طلبات الشراء والتفصيل order_number, total_amount, payment/fulfillment نشط 100%
settings إعدادات وتخصيصات المتجر key, value, group (theme, about, marketing) نشط 100%
promotions كوبونات الخصم والعروض code, discount_type, discount_value, min_order نشط 100%
banners البانرات والشرائح الإعلانية placement, title, image_url, link_url, is_active نشط 100%

٤. تفصيل أقسام لوحة التحكم (Admin Panel Capabilities)

١. إدارة المنتجات والأسعار (/admin/products) تعديل وحذف وإضافة قطع المجوهرات بالدولار ($ USD) والدينار الكويتي (د.ك KWD)، وإدارة حالة التوفر بالمخزون.
٢. إدارة دلايات الاستوديو 3D (/admin/charms) التحكم في دلايات عرق اللؤلؤ والأحرف والرموز، تحديد السعر وتفعيل/تعطيل ظهورها في استوديو التصميم بنقرة واحدة.
٣. محرك العروض والكوبونات (/admin/promotions) إنشاء كوبونات بنسب مئوية أو مبالغ نقدية ثابتة، تحديد حد أدنى للطلب، وتحديد عدد مرات الاستخدام المسموحة.
٤. البانرات والشرائح الإعلانية (/admin/banners) إدارة بنرات الهيرو الرئيسي، الشريط العلوي، والبانر الوسطي مع التحكم في الروابط والصور ونصوص أزرار الشراء.
٥. تخصيص الهيرو وتصميم المتجر (/admin/theme) تغيير نصوص الهيرو، صورة النمر الأسود، الشريط الإعلاني العلوي، وحقوق الفوتر دون الحاجة لأي كود برمجي.
٦. قصة الدار والحرفية اليدوية (/admin/about) تحرير قصة تأسيس الدار، مراحل الصياغة الـ 18، دليل مقاسات المعصم، وبيانات التواصل المباشر مع كونسيرج الأتيليه.

٥. دليل ربط البيكسل الإعلاني وحقن الأحداث (Tracking & Pixels)

تم تزويد المتجر بنظام حقن ذكي عبر لوحة التحكم (`/admin/marketing`) يتيح ربط 5 منصات إعلانية فور إدخال معرّفاتها:

المنصة الإعلانية المعرّف المطلوب الدور التسويقي في الخليج
Meta Pixel Pixel ID (15-16 رقماً) حملات إنستغرام وفيسبوك، الإعلانات المصورة وإعلانات الريلز.
TikTok Pixel TikTok Pixel ID إعلانات الفيديو القصيرة السريعة والوصول للشريحة الشابة.
Snapchat Pixel Snap Pixel ID (UUID) المنصة الأكثر استخداماً في الكويت والسعودية لبناء مبيعات الذهب.
Google Analytics 4 Measurement ID (G-XXXX) تتبع مسار زوار الموقع ومعدل الارتداد والتحويلات المالية.
Google Tag Manager Container ID (GTM-XXXX) إدارة متقدمة للوسوم وربط منصات إعلانية إضافية بسهولة.

الأحداث المعيارية المربوطة تلقائياً (Auto-Fired Standard Events)

• PageView: يطلق في كل صفحات المتجر لبناء جمهور الزوار العام.
• ViewContent: يطلق في صفحة تفاصيل المنتج واستوديو 3D مع اسم القطعة وسعرها وعملتها.
• AddToCart: يطلق فور النقر على "إضافة للسلة" مع قائمة الدلايات وقيمة الإسورة الإجمالية.
• InitiateCheckout: يطلق فور الدخول لصفحة إتمام الطلب /checkout.
• Purchase: يطلق فور نجاح عملية الدفع حاملاً رقم الطلب وإجمالي المبيعات لتحسين خوارزميات الشراء في المنصات الإعلانية.

٦. استراتيجية وخطة التسويق الرقمي لدول الخليج (GCC Marketing Playbook)

المرحلة ١: بناء الأصالة والغموض (Top Funnel) فيديوهات ريلز وسناب تركز على النمر الأسود، الذهب الخالص 14K المقرب، وصوت انزلاق الدلايات السلس بنظام ASMR.
المرحلة ٢: التخصيص التفاعلي (Middle Funnel) توجيه الإعلانات مباشرة إلى رابط استوديو 3D مع كود الخصم الترحيبي 15% NICH15 لتحفيز التفاعل الشخصي.
المرحلة ٣: الاسترداد والشراء (Bottom Funnel) إعادة استهداف زوار السلة المتروكة عبر رسائل كونسيرج الأتيليه وإعلانات الخصم الحصري، مع الشحن المؤمّن المجاني.
المرحلة ٤: إهداء المؤثرين (Influencer Seeding) إهداء أساور منقوشة بأحرف وأسماء أبرز شخصيات الفخامة والموضة في الكويت والرياض ودبي لبناء مصداقية عريقة.
